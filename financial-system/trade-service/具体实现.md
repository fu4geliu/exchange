一.委托：
POST /orders:提交委托（买/卖、数量、价格、客户号、股票代码）
1.前端GET POST /orders
2.gateway验证转发
3.验证角色==OPERATOR
4.入参格式校验：
    customer_code	非空、纯数字
    stk_code	非空、6位数字
    order_qty	正整数、不能为空
    order_price	正数、不能为空、保留不超过2位小数
5.客户资格校验：数据库表user_info + customer_account：
    customer_code 必须存在、cuacct_status = '0'（正常）、cuacct_cls（账户类别，后续算佣金用）
6.证券与行情校验：数据库表security_info + market_quote：
    stk_code 必须存在于 security_info → 否则：证券不存在
    同时取出：market、stk_cls、stamp_tax_rate
    行情必须存在 → 取出：upper_limit_price、lower_limit_price
7.交易规则校验：
    lower_limit_price ≤ order_price ≤ upper_limit_price:委托价格超出涨跌停限制
    数量校验:order_qty % 100 == 0（整手买入，最小100股） order_qty ≥ 100 允许0股（不足100）卖出
8.费用 / 持仓预算：
    if 买入：查佣金费率commission_rate，
        计算：（买入不收印花税）order_amount（order_price × order_qty）+commission_fee  = MAX(order_amount × commission_rate, 5.00)  -- 最低5元
        资金校验：customer_account.cash_balance - customer_account.frozen_cash ≥ 需冻结资金：否则可用资金不足
    if 卖出：查持仓customer_position，
        持仓数量校验：available_qty ≥ order_qty → 否则：可卖数量不足或无可用持仓
        计算费用（仅预估，成交时才实扣）：印花税+commission_fee、order_amount
9.冻结操作（数据库事务）：买入冻结资金，卖出冻结持仓
    UPDATE customer_account
    SET frozen_cash = frozen_cash + #{需冻结资金}
    WHERE customer_code = #{customer_code}
        AND (cash_balance - frozen_cash) >= #{需冻结资金}
    （用 AND 条件做乐观锁，更新行数为0则说明并发导致资金不足，回滚，卖出同理）
10.写入委托记录：（order_status = '2'（没对接真实交易所，默认已报））
    INSERT INTO order_info (
        customer_code, market, stk_code, trd_id,
        order_price, order_qty, order_amount,
        order_status, is_withdraw
    ) VALUES (
        #{customer_code}, #{market}, #{stk_code}, #{trd_id},
        #{order_price}, #{order_qty}, #{order_amount},
        'A', 'F'
    )
GET /orders:委托列表（按客户号/状态/日期过滤）

3.查数据库order_info
