JwtAuthFilter
     │
     ├─ 路径在白名单？（/api/customer/login 等）
     │        │
     │       YES → 直接转发到对应服务
     │
     └─ NO
          │
          ├─ Header 有 Bearer Token？ → NO → 返回 401 "缺少Token"
          │
          └─ YES
               │
               ├─ JwtUtil.parseToken() 验证
               │       │
               │       ├─ 过期 → 返回 401 "Token已过期"
               │       └─ 非法 → 返回 401 "Token无效"
               │
               └─ 验证通过，解析 Payload
                        │
                        ├─ 注入请求头
                        │    ├─ X-Account-Id: account_id
                        │    ├─ X-Role:       OPERATOR / CUSTOMER
                        │    └─ X-Ref-Id:     customer_code（操作员为空）
                        │
                        └─ 按路由转发
                                 │
                       ┌─────────┼──────────┐
                       ▼         ▼          ▼
               customer:9081  trade:9082  market:9083
                       │         │
                       │         └─ X-Role == OPERATOR → 放行
                       │            X-Role == CUSTOMER → 返回 403 "权限不足"
                       │            Controller 从 Header 读取
                       │
                       └─ /api/admin/** 路由
                              │
                              ├─ X-Role == OPERATOR → 放行
                              └─ X-Role == CUSTOMER → 返回 403 "权限不足"
                                   
用 GlobalFilter 还是 GatewayFilter？	GlobalFilter	一处配置全局生效，无需每条路由重复声明
白名单管理	application.yml 配置	灵活，不改代码可扩展
用户信息如何传递	请求头 X-User-Id	下游服务解耦，无需重新解析 JWT
跨域处理	Gateway 统一配置	下游服务无需再配置 CORS
Token 校验失败响应	返回 JSON（非重定向）	前端 axios 统一拦截处理 401
