1）登录页
操作员登录，拿到 JWT,获取当前登录人信息（用于顶部栏显示）
接口
POST /auth/login:校验账号密码 → 签发 JWT
GET /auth/me:前端刷新后，用 token 换取当前用户信息
备注：/auth/login 加到 gateway 白名单；其他接口都需要 token。
2）开户页
录入客户信息(客户名称（姓名）、证件类别、证件号码、资产账户类别),查询客户列表(客户名称,客户代码)
接口
POST /customers:开户
GET /customers:分页查询客户，支持按姓名/证件号/客户号搜索
GET /customers/{customerId}:查看单个客户+资金账户信息
3）委托页
行情参考（输入股票代码自动带出最新价）,提交委托（买/卖）,查看“当前委托列表”
接口
GET /market/quote?symbol=600036:查询当前价格
POST /orders:提交委托（买/卖、数量、价格、客户号、股票代码）
GET /orders:委托列表（按客户号/状态/日期过滤）
4）撤单页
查询“可撤委托”（状态=已报/未成交/部分成交等,按客户号/状态/日期过滤），提交撤单，查看撤单结果
接口
GET /orders/cancellable?customerId=...:列出可撤单的委托
POST /orders/{orderId}/cancel:撤单
GET /orders/{orderId}/cancel:查询撤单记录
5）成交页
查询“可成交委托”（状态=已报/未成交/部分成交等,按客户号/状态/日期过滤），提交成交，查看成交结果
接口
GET /orders/matchable?customerId=...:列出可成交的委托
POST /orders/{orderId}/deals:成交
GET /orders/{orderId}/deals:查询成交记录
6）行情页
展示多只股票行情（列表/分页/搜索）
接口
GET /market/quotes?symbols=600036,000001,600519,...:展示多只股票概览行情
GET /market/detail?symbols=600036:展示某只股票的具体行情
网关路由
/auth/** → customer-service
/customers/** /accounts/** → customer-service
/orders/** /deals/** → trade-service
/market/** → market-service
